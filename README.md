# Притулок

Мобільний застосунок для пошуку, підтримки та усиновлення тварин із притулків України.
Навчальний прототип: Expo (React Native) + TypeScript. Дані зберігаються локально на телефоні, бекенду немає.

## Запуск

```bash
npm install
npx expo start
```

Відкрийте QR-код в застосунку **Expo Go** (Android). Якщо телефон і компʼютер у різних мережах, додайте `--tunnel` (потрібен акаунт Expo).

## Вебверсія та GitHub Pages

Для локальної розробки в браузері: `npm run web`.
Перевірки: `npm run check`. Production-збірка: `npm run export:web` (результат у `dist/web`).

Workflow **Deploy web to GitHub Pages** публікує вебверсію після push у `main`.
У цьому репозиторії відкрийте **Settings → Pages → Source → GitHub Actions**.
Після успішного workflow застосунок доступний за адресою https://sergienkomm-crypto.github.io/pethouse/.
Шлях `/pethouse` задається через `EXPO_BASE_URL` лише під час публікації.
У браузері дані зберігаються локально; реєстрація й оплата залишаються демонстраційними.

## Що вміє
- онбординг з вибором, кого шукаєте і що важливо;
- Головна, Стрічка, Пошук (візуальні фільтри), Чати, Акаунт, профіль тварини;
- реєстрація, підтримка тварини, заявка на знайомство з короткою анкетою;
- легкі анімації та екрани успіху.

## Важливо
- Реєстрація та оплата **умовні**: будь-які 4 цифри коду, гроші не списуються.
- Фото тварин завантажуються з Unsplash, потрібен інтернет.
- Усі тварини, притулки й тексти вигадані.

## Структура
- `App.tsx`: навігація та головні екрани-флоу
- `src/theme.ts`: кольори, відступи, типографіка
- `src/screens/`: екрани, `src/components/`: компоненти
- `src/data/`: мок-дані
